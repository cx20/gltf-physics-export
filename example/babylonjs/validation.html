glTF Physics Round-Trip Validation

For each entry below, this page fetches the upstream source (.glb for the showroom samples, .gltf for the per-feature test suites at eoineoineoin/glTF_Physics/tests), runs it through BABYLON.GLTFPhysicsExport, and checks the result two ways:

  • Round-trip — compares the exported physics extension blocks against the source for semantic equivalence (KHR_implicit_shapes + KHR_physics_rigid_bodies only; geometry / materials are out of scope), then re-loads the export to confirm the same number of physics bodies rebuild.
  • glTF Validator — runs the exported .glb through the official Khronos glTF Validator so the downloadable file is checked for structural correctness (a row fails on any validator error; warnings are listed but do not fail).
